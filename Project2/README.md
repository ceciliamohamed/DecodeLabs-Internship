# Exploratory Data Analysis (EDA) - DecodeLabs Project 2

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on an e-commerce dataset to identify trends, patterns, correlations, and outliers.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

* Data Exploration
* Missing Value Analysis
* Descriptive Statistics
* Product Analysis
* Revenue Analysis
* Referral Source Analysis
* Distribution Analysis
* Outlier Detection
* Correlation Analysis

## Key Insights

* The dataset contains 1,200 customer orders.
* Product revenues vary significantly.
* Several outliers were detected in TotalPrice.
* Referral sources influence revenue generation.
* Quantity and TotalPrice show a positive relationship.
